## 1 常见 Linux 命令及其选项

## 1. `ls` — 列出目录内容
- `ls`：列出当前目录中的文件和文件夹。
- `ls -a`：列出所有文件，包括隐藏文件（以`.`开头的文件）。
- `ls -l`：以长格式列出文件信息（权限、所有者、大小等）。
- `ls -la`：结合 `-a` 和 `-l`，列出所有文件及其详细信息。
- `ls -h`：以易读的格式显示文件大小（例如：KB, MB）。
- `ls -R`：递归列出目录中的所有文件和子目录。

## 2. `cd` — 切换目录
- `cd <dir>`：进入指定目录 `<dir>`。
- `cd ..`：返回上级目录。
- `cd ~`：切换到用户的主目录。
- `cd -`：返回到上次所在的目录。

## 3. `pwd` — 显示当前目录
- `pwd`：打印当前工作目录的绝对路径。

## 4. `cp` — 复制文件或目录
- `cp <source> <destination>`：将 `<source>` 文件复制到 `<destination>`。
- `cp -r <source> <destination>`：递归复制目录及其内容。
- `cp -i <source> <destination>`：在覆盖目标文件时提示确认。

## 5. `mv` — 移动文件或重命名文件
- `mv <source> <destination>`：将 `<source>` 移动到 `<destination>`，或者重命名文件。
- `mv -i <source> <destination>`：在覆盖目标文件时提示确认。

## 6. `rm` — 删除文件或目录
- `rm <file>`：删除指定文件。
- `rm -r <dir>`：递归删除目录及其内容。
- `rm -f <file>`：强制删除文件，不提示确认。
- `rm -rf <dir>`：递归并强制删除目录及其内容。

## 7. `touch` — 创建空文件或更新文件时间戳
- `touch <file>`：创建一个空文件，或者更新已存在文件的时间戳。

## 8. `mkdir` — 创建目录
- `mkdir <dir>`：创建指定的目录。
- `mkdir -p <dir>`：递归创建目录（如果父目录不存在，自动创建）。

## 9. `rmdir` — 删除空目录
- `rmdir <dir>`：删除空目录。

## 10. `cat` — 查看文件内容
- `cat <file>`：显示文件 `<file>` 的内容。
- `cat <file1> <file2> > <output_file>`：将多个文件的内容合并并输出到 `<output_file>`。

## 11. `more` / `less` — 分页查看文件内容
- `more <file>`：分页显示文件内容，可以向下滚动。
- `less <file>`：分页显示文件内容，可以向上和向下滚动，支持更强的搜索和导航。

## 12. `head` — 显示文件开头部分
- `head <file>`：默认显示文件的前10行。
- `head -n <num> <file>`：显示文件的前 `<num>` 行。

## 13. `tail` — 显示文件结尾部分
- `tail <file>`：默认显示文件的后10行。
- `tail -n <num> <file>`：显示文件的后 `<num>` 行。
- `tail -f <file>`：实时查看文件更新内容（常用于查看日志文件）。

## 14. `find` — 查找文件或目录
- `find <dir> -name <filename>`：在 `<dir>` 目录下查找名为 `<filename>` 的文件。
- `find <dir> -type f`：查找目录 `<dir>` 下的所有文件。
- `find <dir> -type d`：查找目录 `<dir>` 下的所有目录。

## 15. `grep` — 搜索文本
- `grep <pattern> <file>`：搜索文件 `<file>` 中匹配 `<pattern>` 的行。
- `grep -i <pattern> <file>`：忽略大小写进行搜索。
- `grep -r <pattern> <dir>`：递归搜索目录 `<dir>` 下的文件。
- `grep -v <pattern> <file>`：显示不匹配 `<pattern>` 的行。

## 16. `chmod` — 修改文件权限
- `chmod <permissions> <file>`：修改文件 `<file>` 的权限。
- `chmod +x <file>`：为文件 `<file>` 增加执行权限。
- `chmod -R <permissions> <dir>`：递归修改目录及其内容的权限。

## 17. `chown` — 修改文件所有者
- `chown <user>:<group> <file>`：将文件 `<file>` 的所有者和所属组修改为 `<user>` 和 `<group>`。

## 18. `ps` — 查看进程
- `ps`：显示当前用户的进程。
- `ps -ef`：显示所有用户的进程。
- `ps aux`：显示详细的进程信息。

## 19. `top` — 动态查看系统资源使用
- `top`：实时显示系统进程和资源使用情况。

## 20. `kill` — 终止进程
- `kill <pid>`：通过进程 ID 终止进程。
- `kill -9 <pid>`：强制终止进程。

## 21. `df` — 查看磁盘使用情况
- `df`：显示文件系统的磁盘使用情况。
- `df -h`：以人类易读的格式（如GB, MB）显示磁盘使用情况。

## 22. `du` — 查看文件或目录的磁盘空间使用情况
- `du <file>`：显示文件或目录占用的磁盘空间。
- `du -sh <dir>`：以易读格式显示目录 `<dir>` 的总占用空间。

## 23. `tar` — 打包和压缩文件
- `tar -cvf <archive.tar> <file>`：创建一个 tar 包。
- `tar -xvf <archive.tar>`：解压 tar 包。
- `tar -czvf <archive.tar.gz> <file>`：创建压缩的 tar 包（使用 gzip）。
- `tar -xzvf <archive.tar.gz>`：解压 gzip 压缩的 tar 包。

## 24. `wget` — 下载文件
- `wget <url>`：从指定 URL 下载文件。
- `wget -c <url>`：断点续传下载文件。

## 25. `curl` — 与 URL 进行数据传输
- `curl <url>`：从指定 URL 获取内容。
- `curl -O <url>`：下载文件并保存为原文件名。

## 26. `man` — 查看命令手册
- `man <command>`：查看命令 `<command>` 的手册页面。

## 27. `alias` — 设置命令别名
- `alias <name>='<command>'`：为命令设置别名。
- `unalias <name>`：删除命令别名。

## 28. `history` — 查看命令历史
- `history`：显示历史命令。
- `!<number>`：执行历史命令列表中编号为 `<number>` 的命令。

---

这些是最常见的 Linux 命令及其选项，掌握这些命令可以有效提升使用 Linux 系统的效率。



## 2 宏与内联函数

内联函数（**inline function**）和宏（**macro**）在 C++ 编程中都可以用来提高代码的效率，但它们有着显著的区别。以下是它们的主要差异：

### 1. **定义和行为**

- **内联函数：**
  - **内联函数**是由编译器在调用时将函数的代码嵌入到调用点的地方，而不是进行常规的函数调用。
  - 在函数前加上 `inline` 关键字，表示请求编译器将该函数作为内联函数处理（尽管编译器可以选择是否内联化）。
  - 语法上和普通函数一样，能执行复杂的逻辑和运算，且有明确的返回值类型。

  ```cpp
  inline int add(int a, int b) {
      return a + b;
  }
  ```

- **宏：**
  - **宏**是由预处理器在编译之前进行文本替换的。它通过 `#define` 定义，可以是简单的常量替换，也可以是函数样式的代码替换。
  - 宏并不执行任何类型检查，宏展开只是简单的文本替换，可能会引发潜在的错误或副作用。

  ```cpp
  #define ADD(a, b) ((a) + (b))
  ```

### 2. **类型安全**

- **内联函数：**
  - **类型安全**：内联函数在编译时会进行类型检查，能够检测到类型错误，像普通函数一样对参数类型和返回值类型进行检查。
  
  ```cpp
  inline int add(int a, int b) {
      return a + b;
  }
  // 编译器会检查类型是否正确
  ```

- **宏：**
  - **不类型安全**：宏在预处理时是简单的文本替换，没有类型检查，可能导致运行时错误。例如，传入宏的参数可能会被错误地展开，造成意外的结果。

  ```cpp
  #define SQUARE(x) ((x) * (x))
  SQUARE(3+1);  // 结果是 3+1*3+1，错误的结果
  ```

### 3. **调试支持**

- **内联函数：**
  - **有调试信息**：内联函数是由编译器处理的，通常具有调试支持。内联函数的代码可以在调试时查看，且函数名等信息也会保留。

- **宏：**
  - **无调试信息**：宏展开发生在预处理阶段，因此调试时无法看到宏展开后的代码，也无法追踪到宏的调用栈。调试时，如果出错，错误信息通常不提供足够的上下文。

### 4. **代码替换与副作用**

- **内联函数：**
  - **没有副作用**：内联函数像普通函数一样执行，并且每个调用都会按规范进行，无副作用。可以保证预期的行为。

- **宏：**
  - **可能引起副作用**：由于宏是简单的文本替换，宏的参数如果包含有副作用的表达式（如 `x++` 或 `f()`），可能会导致多次计算或意外的副作用。

  ```cpp
  #define INCREMENT(x) ((x)++)
  int a = 5;
  INCREMENT(a);  // a 会被增加两次，可能是意外行为
  ```

### 5. **执行效率**

- **内联函数：**
  - **可能提高效率**：如果函数较小，且编译器决定将其内联，避免了函数调用的开销（如堆栈操作）。但如果函数体过大，内联反而可能导致代码膨胀，影响效率。
  - 内联函数的效率依赖于编译器的决定，编译器会根据函数的大小和复杂度来判断是否内联。

- **宏：**
  - **不涉及函数调用开销**：宏在预处理阶段就完成替换，因此没有函数调用的开销，通常执行时速度较快。
  - 但宏展开可能导致代码膨胀，影响可读性和维护性，特别是在宏复杂时。

### 6. **作用范围**

- **内联函数：**
  - **作用域明确**：内联函数在定义的作用域内有效，并且在调用时会按正常的作用域规则查找。它是一个符号，具有具体的作用域。

- **宏：**
  - **作用域不明确**：宏替换发生在预处理阶段，因此其作用范围是全局的，不受函数或代码块的限制。如果在不同地方定义了相同名称的宏，可能会导致命名冲突。

### 总结

| 特性         | 内联函数                         | 宏                                     |
| ------------ | -------------------------------- | -------------------------------------- |
| **类型检查** | 进行类型检查                     | 不进行类型检查                         |
| **调试支持** | 有调试信息                       | 无调试信息                             |
| **副作用**   | 无副作用                         | 可能有副作用                           |
| **执行效率** | 可能提高效率，但依赖于编译器决定 | 不涉及函数调用开销，但可能影响可维护性 |
| **作用域**   | 具有作用域限制                   | 作用域广泛，可能引发命名冲突           |

总之，**内联函数**更安全、可维护、易于调试，适合用于逻辑较简单但需要提高性能的函数；而**宏**是预处理阶段的简单文本替换，适用于常量和简单的代码替换，但它没有类型安全和调试支持，使用时需要小心。



## default关键字

在C++中，`default`关键字用于显式指示编译器为类的特殊成员函数生成默认实现。它让代码意图更清晰，并能在某些场景下解决自动生成规则的限制。以下是详细解析：

---

### **1. 核心用途**
`default`主要用于以下6种特殊成员函数：
1. **默认构造函数**  
2. **拷贝构造函数**  
3. **拷贝赋值运算符**  
4. **移动构造函数**  
5. **移动赋值运算符**  
6. **析构函数**

当这些函数未被用户显式定义时，编译器会自动生成它们的默认版本。但若用户定义了其他相关函数（如带参数的构造函数），编译器可能不再生成某些默认函数，此时可通过`= default`显式要求生成。

---

### **2. 典型场景**
#### **场景1：保留默认构造函数**
当用户定义了其他构造函数（如带参数的构造函数），编译器不再生成默认构造函数。此时可用`= default`显式保留：
```cpp
class Example {
public:
    Example(int x) {}       // 自定义构造函数
    Example() = default;    // 显式保留默认构造函数
};
```
未使用`= default`时，`Example obj;`会因找不到默认构造函数报错。

#### **场景2：控制函数是否为内联**
- 类内声明`= default`：生成的函数是内联的。
- 类外声明`= default`：生成的函数是非内联的。
```cpp
// 类内（内联）
class Example {
public:
    Example() = default;
};

// 类外（非内联）
class Example {
public:
    Example();
};
Example::Example() = default;  // 非内联
```

#### **场景3：生成移动操作**
若用户定义了拷贝操作或析构函数，编译器不会自动生成移动操作。需手动用`= default`：
```cpp
class Example {
public:
    Example(const Example&) { /*...*/ }  // 自定义拷贝构造函数
    Example(Example&&) = default;        // 显式生成移动构造函数
};
```

#### **场景4：虚析构函数保留默认行为**
需要虚析构函数但不想手动实现时，可结合`virtual`和`= default`：
```cpp
class Base {
public:
    virtual ~Base() = default;  // 虚析构函数，默认实现
};
```

---

### **3. 注意事项**
- **仅适用于有默认实现的函数**：不能对普通函数或参数化构造函数使用`= default`。
- **成员兼容性**：若类的成员无法被默认构造、拷贝或移动（如引用类型、`const`成员），使用`= default`会导致编译错误。
- **异常声明**：默认生成的函数保留编译器的异常特性（如移动操作默认为`noexcept`）。
- **与`= delete`对比**：`= delete`用于禁用函数，`= default`用于显式启用。

---

### **4. 示例代码**
#### 保留移动操作
```cpp
class Data {
public:
    Data() = default;
    Data(const Data&) { /* 深拷贝逻辑 */ }
    Data(Data&&) = default;  // 显式生成移动构造函数
};
```

#### 虚析构函数
```cpp
class Base {
public:
    virtual ~Base() = default;  // 虚析构函数，默认实现
};
```

---

### **5. 为什么要用`= default`？**
- **代码清晰**：明确告知编译器或开发者“需要默认行为”。
- **避免隐式规则**：在用户定义其他构造函数后，仍可保留默认构造。
- **优化行为**：默认生成的函数可能比手动空实现更高效（如支持`trivial`优化）。

---

### **总结**
`default`关键字简化了特殊成员函数的定义，尤其在需要保留编译器自动生成的默认行为时。合理使用它能让代码更简洁、意图更明确，同时规避手动实现的潜在问题。
